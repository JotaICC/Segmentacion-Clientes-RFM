Segmentación de Clientes mediante RFM
Descripción
Este proyecto analiza el comportamiento de compra de los clientes mediante la metodología RFM (Recencia, Frecuencia y Valor Monetario), con el objetivo de identificar diferentes segmentos de clientes y generar información útil para la toma de decisiones.

El análisis fue desarrollado utilizando Python y complementado con un dashboard interactivo en Power BI.

Objetivo
Analizar el comportamiento de los clientes a partir de sus compras y clasificarlos en diferentes segmentos según su recencia, frecuencia de compra y valor monetario.

Metodología
El análisis se desarrolló mediante las siguientes etapas:

Carga y exploración de los datos
Limpieza y transformación de los datos
Cálculo de las métricas RFM
Asignación de puntuaciones
Segmentación de clientes
Análisis de los resultados
Visualización mediante Power BI
Variables RFM
Recencia (Recency): tiempo transcurrido desde la última compra del cliente.
Frecuencia (Frequency): cantidad de compras realizadas por el cliente.
Valor Monetario (Monetary): monto total gastado por el cliente.
Segmentos de clientes
El análisis clasifica a los clientes en cuatro segmentos:

VIP
Leal
Regular
En Riesgo
Estos segmentos permiten identificar diferentes comportamientos de compra y plantear estrategias orientadas a la fidelización y retención de clientes.
